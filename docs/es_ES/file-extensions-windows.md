# Extensiones de archivo (Windows)

Esta es una sección adicional para desactivar el comportamiento predeterminado de Windows de ocultar las extensiones de archivo, lo que facilitará mucho la búsqueda de archivos referenciados en la guía.

::::: tabs

:::: tab default Windows 11

1. Inicia el explorador de archivos. Puedes hacerlo abriendo cualquier carpeta (como la de tu tarjeta SD), o presionando el ícono en la barra de tareas.
2. Haz clic en la opción "Ver" en la barra superior
   - Si la opción no está presente, haz clic en el botón `···` en la parte derecha de la barra superior.
3. Haz clic o mantén el cursor en el submenú `Mostrar >`
4. Activa la opción `Extensiones de nombres de archivo`
   ![Captura de la casilla de verificación "Extensión de nombres de archivo" en Windows 11](/assets/images/windows-11-file-extensions.png)

::::

:::: tab Windows 10 / 8.1 / 8

1. Inicia el explorador de archivos. Puedes hacerlo abriendo cualquier carpeta (como la de tu tarjeta SD), o presionando el ícono en la barra de tareas.
2. Haz clic en la opción "Ver" en el menú de cinta de la barra superior
3. Activa la opción `Extensiones de nombres de archivo`
   ![Captura de la casilla de verificación "Extensión de nombres de archivo" en Windows 10](/assets/images/windows-10-file-extensions.png)

::::

:::: tab Windows 7 / Vista / XP

1. Abre el menú de inicio haciendo clic en él o usando la tecla Windows
2. Busca "Opciones de carpeta" y selecciona el resultado correspondiente
   ![Captura de una búsqueda de "folder options" (opciones de carpeta en inglés) en el menú Inicio de Windows 7](/assets/images/windows-7-folder-options-start-menu.png)
3. Haz clic en la opción "Ver" en la parte superior del menú Opciones de carpeta
4. Asegúrate de que la casilla "Ocultar extensiones para tipos de archivo conocidos" no está marcada
   ![Captura de la ventana "Opciones de carpeta" en Windows 7 con la opción "Ocultar extensiones para tipos de archivo conocidos" desmarcada](/assets/images/windows-7-folder-options.png)
